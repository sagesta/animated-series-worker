## Honest capability statement

Animated Series Studio now implements a default non-technical Creator Mode over the full local production control plane. A creator can begin with an idea or existing script, then see one derived next step, one primary request action, and one compact creative-progress indicator while the complete production run stays available under one disclosure. That durable run is story package, character/location references, storyboard frames, voices/dialogue, video shots, local edit/sound/captions, verified master, and worker cleanup. A secondary one-off tool prepares an image, video, audio item, composition, or local assembly without bypassing prerequisites or starting work. AI-prepared production-plan, cast, world, screenplay, storyboard, animation-look, voice, and release stages no longer require manual room, model, canon, or skill selection. The same durable stores manage multiple isolated series and one-off films; promote reviewed facts into versioned canon; import, type-check, view, approve, reject, copy, and lineage-track media; prepare governed Qwen image/Qwen3-TTS/LTX-2.5/LatentSync plus locked control/foley/adaptation candidates; assemble rights-reviewed adaptation datasets; estimate and separately approve RunPod spend; create/reconcile/terminate one worker per job; transfer and verify media; render local timelines, captions, thumbnails, and manual YouTube packages; and store structured project-local performance evidence from manual entry, rehearsal, or a checked official-report CSV plus human-reviewed future lessons. Advanced Studio retains the detailed controls.

The checkout still cannot start paid production generation. A controlled RunPod L40S qualification on 2026-08-26 published and canonically signed candidate `0.10.1-candidate.5` at `ghcr.io/sagesta/animated-series-worker@sha256:3b1142ede47d387a890b36e7e5e0ae212c3f2304387e128f4f7991ad5c33b0e9`; protected GitHub OIDC run `32994632107` verified the exact manifest/config pair and workflow identity. Preflight proved the 48 GB GPU class, pinned runtime, nine workflow hashes, and 11 exact model hashes. One uninterrupted sequence technically completed identity image, targeted edit, voice design, two-line TTS, LTX draft, LTX final, and assistive QC with hash-verified downloads. The same Pod was explicitly deleted after 73.923 minutes and a follow-up provider query returned no Pod. Production promotion remains blocked: the targeted edit left the scarf red instead of blue and changed framing; the requested one-second final video was 0.75 seconds; subjective media review and several recovery/shutdown/cost gates remain incomplete; model storage was Pod-local and non-persistent; the model receipt was reconstructed from the live capability report rather than preserved from bootstrap; and exact Gemma encoder provenance remains open. D-054 still excludes LatentSync and its Stability VAE. No production pack or readiness receipt was created. See [live GPU qualification](LIVE_GPU_QUALIFICATION_2026-08-26.md).

## External qualification boundary

The release-engineering path is implemented in:

- `scripts/New-GpuQualificationBundle.ps1` — creates a no-cost evidence workspace;
- `scripts/Import-ComfyWorkflow.mjs` — imports and hashes reviewed API-format candidate workflows;
- `scripts/Build-GpuWorker.ps1` — builds matching candidate or promoted images;
- `worker/bootstrap_models.py` — downloads only manifest-pinned model sources and computes hashes;
- `worker/preflight.mjs` — records exact image/pack/runtime/GPU/node/model/workflow capability;
- `scripts/Promote-GpuWorker.mjs` — creates production pack, model manifest, and readiness receipt only when all evidence passes.

The promotion tool will not overwrite an earlier production release. Changing a pack, template, source pin, model hash, or image digest relocks generation until the new candidate passes again.
